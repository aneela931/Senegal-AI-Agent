# Senegal Agent App — Katalon

Frontend Android UI automation for Senegal Agent App (Yas Agent). This folder is the launchable project from `create-katalon-project`, plus the framework scaffold from `build-katalon-framework`.

**Read [docs/README.md](docs/README.md)** for how to open the project, pick staging, run local ADB or Test Execution Cloud, and find reports.
